In the Help dialog, Tab moves between controls, Enter opens a topic, and Esc closes the dialog.
Use **Back** to return to the previous view or **All topics** to browse the index.

Tab to a chart and use the left and right arrow keys to move between dates or bars. On bar
charts, Right moves up and Left moves down. The readout announces the active value. Press
Enter or Space to lock it and Esc to unlock it. Use **View data** for a table or **Download CSV**
to save the values.
