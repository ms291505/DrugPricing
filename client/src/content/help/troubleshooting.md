- **No results.** Check the spelling and dates, or try a shorter term of at least five
  characters. Check the counts under **Include** for hidden results. A result that two boxes hide
  isn’t counted, so if the table says filters hid everything, use the fix it offers. You can
  also try the other search source.
- **Search is disabled.** Check the minimum length. If the current results already match the
  terms, edit the terms to run another search.
- **A package has no prices.** Choose **All** under **NADAC price dates** to check for a price in another week.
  In FDA search, select **Results without prices** under **Include** to see packages even when
  they have no matching price. See [why a package might have no NADAC price](/help/nadac).
- **The price looks unusual.** Check whether it is per tablet, milliliter, gram, or another
  unit, and check the selected dates.
- **The app asks you to reload.** You changed the workspace in another browser tab or window.
  Reload the one that asks before making more changes. Settings changes don’t need a reload.
- **Workspace tabs are missing.** Open the browser and profile where you saved them. Clearing this
  site’s data removes your workspace.
- **A search is slow.** Try a shorter date range or more specific search terms.
