| You have | Use | Why |
| --- | --- | --- |
| A brand name such as `Ozempic` | **Brand name** in FDA search | Finds matching products under that brand |
| An ingredient name such as `semaglutide` | **Generic name** in FDA search | Finds matching listings across brands and generic products |
| A package NDC | **NDC** in NADAC search | Looks up the package’s price history |
| A discontinued drug or an empty FDA search | **Description** in NADAC search | Searches historical prices for packages missing from the current FDA directory |
| A strength or form such as `metformin er 750` | **Description** in NADAC search | Matches the strength and form in the NADAC description |

In FDA search, use **More filters** to narrow results by dosage form, route, or labeler.
