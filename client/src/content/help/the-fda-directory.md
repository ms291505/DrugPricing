The FDA’s National Drug Code Directory contains drug listings submitted by labelers. Entries
include brand and generic names, strength, dosage form, route, labeler and package details.

NADAC uses short descriptions such as “ELIQUIS 5 MG TABLET.” The directory supplies the extra
fields that let you search by generic name or narrow results by dosage form, route or labeler.

FDA search pairs entries from the app’s current FDA directory with matching NADAC prices. Try
NADAC search for historical prices on packages that have dropped out of the directory.
